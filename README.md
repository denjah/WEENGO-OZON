# WEENGO — Maccabi Mini

Рабочая ревизия первого тестового набора карточек для складного настольного футбола Maccabi Mini.

## Открыть ревизию

**[Интерфейс для дизайнера](https://denjah.github.io/WEENGO-OZON/)**

В интерфейсе доступны:

- карточки в порядке исходных файлов `photo_1 … photo_10`;
- актуальные замечания арт-директора из `ПРАВКИ_MACCABI_MINI.md`;
- приоритет каждого замечания и связанный чек-лист;
- графические стрелки и пины поверх макетов;
- сводное ТЗ по всему набору.

Публичная версия работает в режиме просмотра. Локальная версия поддерживает сохранение статусов и графических пометок.

```powershell
python weengo_console/server.py
```

После запуска открыть <http://localhost:7799/>.
